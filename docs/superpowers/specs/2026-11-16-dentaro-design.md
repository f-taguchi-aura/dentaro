# でんたろー v1 設計（アプリ本体）

- 制作者名：もんたろー（Montaro）／アプリ名：でんたろー（dentaro）
- Bundle ID / パッケージ名：`jp.montaro.dentaro`

## 目的・背景
- 自分用。事業の KPI 計算で、2つの独立した電卓を同時に使いたい。
- 普段は通常の電卓として使い、計算の途中でも2画面（2重表示）に切り替えられる。2台の間の連携は不要。
- 別機能として「お得比較」（容量と値段から1単位あたりの価格を出し、最安を判定）を持つ。

## ゴール
1. **電卓**：1画面（通常電卓）⇔ 2画面（独立した電卓2台、縦向き=上下・横向き=左右）を、計算の途中でも切り替えられる。
2. **お得比較**：電卓とは別機能。画面下のタブで行き来する。
3. モダン・モノクロ基調・シンプルなUI。ライト/ダーク両対応。
4. iPhone / Android 両対応。

## 非ゴール（v1 ではやらない）
- ウィジェット（ホーム画面・通知欄）→ 第2段階で別設計。
- 電卓間の値の受け渡し、関数電卓機能、履歴一覧画面、負の数の直接入力。
- お得比較での単位換算（g↔kg 等）。
- 広告・課金・ストア公開。

## アンチゴール（動いても失敗とみなすもの）
- キー入力の遅延・取りこぼし。片方の電卓の操作がもう片方に影響する。
- 1画面⇔2画面の切り替えで計算内容が消える。
- 0.1 + 0.2 = 0.30000000000000004 のような浮動小数点誤差が表示される。
- ボタンや装飾が多くてごちゃつく。

## 制約
- 既存の Expo（SDK 58, Expo Router, TypeScript）プロジェクト上に構築。
- v1 は Expo Go で動く範囲（ネイティブ追加モジュールなし）に収める。
- `npm test` / `npm run typecheck` / `npm run lint` が通ること。

## 作り方の検討（Approaches）
- **A. 既存 Expo プロジェクトに画面を追加（採用）**：計算ロジックを純粋な TS モジュールにし単体テスト、各電卓は独立した状態を持つ。第2段階のウィジェットも同じプロジェクトにネイティブターゲットとして追加できる。
- B. Swift / Kotlin でネイティブ別実装：ウィジェットとの親和性は高いが、コード量が約2倍。v1 には過剰。
- C. Web アプリ（PWA）：ウィジェット化できず、第2段階につながらない。
- ユーザーは作り方を任せたため、A を Claude の判断で選択。

## 決まった仕様（ユーザー合意済み）
- 通常電卓 → 計算途中でも2画面電卓に移行できる。2台は独立、連携なし。
- お得比較は電卓とは別機能。
- 強調色はバーガンディ。
- ウィジェットは後回し。ウィジェットはアプリと状態を共有しない独立した電卓。

## 画面構成（Claude の提案・ユーザー了承済み）
```
┌──────────────────────┐
│  [ 1画面 | 2画面 ]   │ ← 計算途中でも切り替え可
│      （電卓）        │
├──────────────────────┤
│  🧮 電卓 │ 🏷 お得比較 │ ← 下部タブ
└──────────────────────┘
```
- 内部に電卓 A・B の2台分の状態と「最後に触った電卓」を持つ。
- 1画面 → 2画面：今計算中の電卓が上（横向きは左）に来る。もう一方は前回の内容のまま（初回は空）。
- 2画面 → 1画面：最後に触った電卓が残る。どちらの切り替えでも内容は消えない。

## Claude の判断（提案・レビューで変更可）
### 電卓
- キー（4列×5行）：`AC ⌫ % ÷` / `7 8 9 ×` / `4 5 6 −` / `1 2 3 +` / `0(2列) . =`。
- 入力中の式を表示（例 `12,500 × 3.2%`）し、下に結果をプレビュー。
- 演算子の優先順位は通常の数式どおり（× ÷ が先）。
- `%` の挙動：`a × b%` = a×b/100、`a + b%` = a + a×b/100（一般的な電卓と同じ）。
- 小数は 10 進演算ライブラリで誤差を出さない。数字は15桁まで。
- 3桁カンマ区切り。表示桁が溢れたら文字を縮小。
- 両電卓の状態・1画面/2画面・最後に触った電卓を端末に保存し、再起動後も復元。

### お得比較
- 行 = 名前（任意）・価格・容量。最低2行、最大6行、追加/削除可。
- 単位は全行共通のラベル1つ（ml, g, 個 など自由入力）。換算はしない。
- 各行に「1単位あたり価格」を表示し、最安の行を強調（★）。同額は全部 ★。
- 入力は OS の数字キーボード。内容は端末に保存。

### デザイン
- 白黒グレーの基調＋強調色1色（演算子キー・最安表示・選択中のタブ/切替のみ）。
- 強調色（バーガンディ）：ライト `#7A1E2E`、ダーク `#B23A4E`（暗背景での視認性のため明るめ）。
- 角丸の大きめキー、細めの数字フォント、余白多め。
- 2画面の境界は細線のみ。操作中の電卓をわずかに強調。

## 第2段階（ウィジェット）への備え（ユーザー合意済み）
- ウィジェットはアプリとは**別の独立した電卓**。アプリと状態を共有しない → v1 の保存先は通常のアプリ内ストレージでよい（App Group 不要）。
- iOS ウィジェットは Swift で計算ロジックを再実装することになるため、v1 の計算ロジックのテストケースは**言語非依存のデータファイル**（`src/calc/test-vectors.json`）として持ち、TS のテストはそれを読み込んで検証する。将来の Swift 実装も同じファイルで検証する。
- 計算ロジックは UI から独立した純粋関数（キー入力 → 新しい状態）として実装する。

## ビルダーに任せる部分

- ファイル構成（`src/app` は画面のみ、ロジックは `src/` 配下）。
